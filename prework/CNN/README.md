# 🎯 AI Vision Platform

Derin öğrenme ve transfer öğrenme tekniklerini kullanarak görüntü sınıflandırması yapan web uygulaması.

## 🌟 Özellikler

- **4 Farklı Analiz Alanı**:
  - 🍇 Üzüm Hastalıkları Tespiti
  - 🌴 Hurma Çeşitleri Sınıflandırması
  - 🐟 Balık Türleri Tanıma
  - 🍚 Pirinç Çeşitleri Ayırt Etme

- **Dual Mimari**: Deep Learning ve Transfer Learning modelleri
- **Çift Dil Desteği**: Türkçe ve İngilizce
- **Kullanıcı Geri Bildirimi**: Tahminler için feedback sistemi
- **Modern Arayüz**: Streamlit tabanlı, responsive tasarım

## 🎓 Kullanım

1. Ana sayfada analiz alanını seçin
2. Model mimarisini seçin (DL veya TL)
3. Görüntünüzü yükleyin
4. Sonuçları inceleyin
5. Geri bildirim verin

## 🔧 Teknolojiler

- **Frontend**: Streamlit
- **ML Framework**: TensorFlow/Keras
- **Image Processing**: PIL, NumPy
- **Python**: 3.8+
